# RandomJokes

Watch the demo video [here](https://youtu.be/2JEyWoVJFJ0).

RandomJokes is a lighthearted web application designed to bring joy and relaxation to users by delivering random jokes and adorable dog pictures. Developed as a two-person group project using JavaScript, HTML, and CSS, RandomJokes ensures a seamless and delightful experience across desktop and mobile devices.

## Features

- **Random Jokes**: Enjoy a wide variety of jokes to lighten your mood.
- **Dog Pictures**: Delight in random dog pictures alongside jokes for an extra dose of happiness.
- **Responsive Design**: Built with mobile-first principles and media queries, ensuring accessibility for both desktop and mobile users.
- **Engaging Presentation**: Includes a video demo showcasing the app's features and user interface.

## Technologies Used

- **Frontend**: JavaScript, HTML, CSS
- **Responsive Design**: Media queries for optimized viewing across devices
- **Agile Methodologies**: SCRUM board for task management and collaboration

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/username/randomjokes.git
   ```
2. Navigate to the project directory:
   ```bash
   cd randomjokes
   ```
3. Open the `index.html` file in your browser to explore the app locally.

## Usage

1. Open the app.
2. View a random joke displayed on the page upon loading.
3. Use the form to:
   - Fetch a new random joke.
   - Fetch a list of ten random jokes.
   - Fetch a new joke based on the type of joke.
4. Enjoy a random dog picture accompanying your joke for extra cheer.

## API Routes

- **Random Single Joke**: [Official Joke API - Single Joke](https://official-joke-api.appspot.com/random_joke) 
  - Returns a random joke with the following properties: `id`, `type`, `setup`, `punchline`.

- **Random Ten Jokes**: [Official Joke API - Ten Jokes](https://official-joke-api.appspot.com/random_ten)
  - Returns an array of ten random jokes with the same properties as a single joke.

- **Random Dog Picture**: [Dog CEO API](https://dog.ceo/dog-api/documentation/)
  - Returns a random dog image URL for display.
